# Global Remote Job Hunter Bot 🚀

A lightweight automation script written in Python designed to scrape and filter live tech opportunities from distributed job networks. Built to bypass standard regional filters and prioritize "Worldwide/Anywhere" roles in Customer Success, Technical Account Management, and Tier-2 Tech Support.

## 💡 Project Motivation
As a technology professional based in Zambia, navigating global job markets often means dealing with hidden geographic restrictions on mainstream boards. I built this tool to automate my own job hunt—filtering through thousands of listings to surface roles that actively hire globally and value cross-functional technical skill sets.

## 🛠️ Features & Tech Stack
* **Language:** Python 3
* **Data Engine:** Consumes live REST API data from distributed networks (Remotive API engine).
* **Smart Filtering:** Logic arrays scanning for specific B2B SaaS keywords (Customer Success, Technical Support Engineer, Account Management) while strictly enforcing global remote parameters (`Worldwide`, `Anywhere`).
